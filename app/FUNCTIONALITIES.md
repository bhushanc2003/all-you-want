# All You Want - Functionality & High-SEO Roadmap Tracker

> **All You Want** is a high-performance, privacy-focused, 100% client-side web utility directory and tool hub. It provides instant online tools for high-intent search queries like **PDF to Word**, **JSON to YAML**, **XML to JSON**, **JWT Debugger**, **Base64 Encoder**, and **CSS Glassmorphism Generator**.

## 🎯 Active & Catalogue High-SEO Tools (20+ Tools Directory)

### 🟢 Live Active Client-Side Tools (Phase 1 Initial Launch)

1. **🔄 JSON ⇆ YAML Converter**
   - **Key Features**: Bi-directional conversion between JSON and YAML, instant inline syntax error detection, custom indentation settings, sample data generator, copy & download options (`.json` or `.yaml`).
   - **SEO Keywords**: `json to yaml`, `yaml to json`, `json formatter`, `yaml validator`, `config converter`.

2. **🔀 XML ⇆ JSON Converter**
   - **Key Features**: Instant XML to JSON & JSON to XML converter using high-precision parser, sample XML structure loader, formatted output, download & copy.
   - **SEO Keywords**: `xml to json`, `json to xml`, `convert xml online`, `xml structure parser`, `soap to json`.

3. **🔐 Base64 Encoder & Decoder**
   - **Key Features**: Instant text encoding/decoding, URL-safe Base64 mode, character/byte counters, file-to-Base64 encoder with preview, single-click copy & text download.
   - **SEO Keywords**: `base64 encode`, `base64 decode`, `base64 converter`, `url safe base64`, `file to base64`.

4. **🔑 JWT (JSON Web Token) Debugger & Visualizer**
   - **Key Features**: Client-side JWT parsing, color-coded visual inspector for Header, Payload, and Signature, automatic human-readable date decoding for `exp`/`iat`/`nbf` with token status badges (Active/Expired).
   - **SEO Keywords**: `jwt decoder`, `decode jwt token online`, `json web token inspector`, `jwt timestamp parser`.

5. **🎨 CSS Glassmorphism & Gradient Generator**
   - **Key Features**: Real-time visual CSS tool with interactive sliders for backdrop blur, opacity, border radiance, and shadow depth. Multi-color gradient generator, live interactive preview with customizable backdrops, and instant CSS copy button.
   - **SEO Keywords**: `glassmorphism generator`, `css backdrop blur`, `frosted glass css`, `gradient generator`, `ui css generator`.
